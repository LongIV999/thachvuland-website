# ThachVuLand 2026 - Modern Corporate Luxury Website

Trang web bất động sản cao cấp với thiết kế hiện đại, kết hợp phong cách Corporate chuyên nghiệp và Minimalist tinh tế.

## 🎨 Design Concept

**"Modern Corporate Luxury"** - Kết hợp sự uy tín, chuyên nghiệp của phong cách Corporate với sự tinh tế, hiện đại của Minimalism.

### Triết Lý Thiết Kế
```
"Nơi Niềm Tin Gặp Gỡ Đổi Mới"
- Trust through Transparency (Minh bạch pháp lý)
- Modern through Innovation (Công nghệ hiện đại)
- Luxury through Simplicity (Sang trọng qua sự tối giản)
```

## 🔧 Customization

### Changing Colors
Edit CSS variables in `styles/main.css`:
```css
:root {
  --primary-700: #004d40;  /* Main brand color */
  --accent-gold: #C5A059;  /* Accent color */
  /* ... other colors */
}
```

### Changing Content
Edit the HTML in `index.html`:
- Update text content
- Replace images (use Unsplash URLs or local images)
- Modify project data
- Update contact information

### Adding Pages
1. Create new HTML file
2. Copy header and footer from index.html
3. Link CSS and JS files
4. Add navigation links
